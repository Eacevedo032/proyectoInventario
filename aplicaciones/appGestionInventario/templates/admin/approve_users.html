Gestión de Usuarios

Esta sección aprueba, deniega o deja pendiente cada registro que efectúan los usuarios. Más Información aquí.

✔Pendientes de Verificar: Usuarios registrados que aún no han sido aprobados ni denegados.

Botón "Aprobar": Activa al usuario automáticamente para que pueda acceder al sistema como usuario no administrador.

Botón "Denegar": Elimina el registro de usuario. El usuario ni siquiera existirá.

✔ Usuarios Aprobados: Aquellos que han sido activados y tienen acceso al sistema.

Botón "Borrar usuario": Borra al usuario de la lista de usuarios aprobados en la Base de Datos, pero aún seguirá estando activo en el sistema. Para mayor ajuste debe dirigirse al Panel Administrativo.

Botón "Eliminar usuario": Borra al usuario de la lista de usuarios aprobados en la Base de Datos, también elimina al usuario permanentemente del sistema.

Botón "Borrar a Todos los Usuarios Aprobados": Borra a todos los usuarios aprobados en la Base de Datos, pero siempre seguirán estando activos. Para mayor ajuste debe dirigirse al Panel Administrativo.

✔ Usuarios Denegados: Registros de usuarios rechazados por no cumplir los requisitos. Su registros están eliminados.

Botón "Borrar usuario": El usuario no existe en el sistema ya que fue denegado. Esta botón únicamente borra al usuario de la lista de usuarios denegados en la Base de Datos.

Botón "Borrar a Todos los Usuarios Denegados": Los usuarios no existen en el sistema ya que sus registros de usuario fueron denegados, por ende, eliminados. Este botón solamente borra a todos los usuarios denegados en la Base de Datos.
